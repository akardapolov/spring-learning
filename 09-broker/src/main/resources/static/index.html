1. Что такое Message Broker

Message Broker (брокер сообщений) — это программный компонент, который принимает сообщения от producer'ов, временно хранит их и передаёт consumer'ам.

Брокер позволяет сервисам обмениваться данными асинхронно — отправитель не ждёт, пока получатель обработает сообщение.

flowchart LR A[Producer] --"отправляет сообщение"--> B["Message Broker"] B --"передаёт сообщение"--> C[Consumer]

Когда используется:

  • Асинхронная обработка задач
  • Отделение тяжёлых операций от основного потока
  • Микросервисная коммуникация
  • Буферизация при пиковых нагрузках
  • Надёжная доставка сообщений

2. ActiveMQ Classic

Apache ActiveMQ Classic — зрелый и надёжный брокер сообщений с богатой экосистемой.

Ключевые особенности:

  • Поддержка протоколов: JMS, OpenWire, STOMP, AMQP
  • Embedded режим (внутри JVM)
  • Jakarta JMS — Spring Boot 3.x
  • Простота настройки и эксплуатации
  • TCP-коннектор для доступа внешних сервисов

3. Queue vs Topic

Характеристика Queue (Point-to-Point) Topic (Pub/Sub)
Модель Одно сообщение = один consumer Одно сообщение = все subscribers
Доставка Гарантированно один раз одному получателю Каждому подписчику
Когда использовать Задачи, обработка заказов, email-рассылки Уведомления, события, логи
Spring JMS jmsTemplate.convertAndSend("queue", msg) jmsTemplate.setPubSubDomain(true)

4. Producer / Consumer паттерн

Producer создаёт и отправляет сообщения в брокер.
Consumer получает и обрабатывает сообщения из брокера.

Компоненты Spring JMS:

  • JmsTemplate — для отправки сообщений (Producer)
  • @JmsListener — для получения сообщений (Consumer)
sequenceDiagram participant P as Producer (JmsTemplate) participant B as Broker (ActiveMQ) participant C as Consumer (@JmsListener) P->>B: convertAndSend("demo-queue", "hello") B->>B: сохранить в очередь C->>B: poll / push B-->>C: доставить сообщение C->>C: обработать сообщение

5. Spring JMS

Spring JMS упрощает работу с брокерами через:

@EnableJms

Включает поддержку JMS-листенеров:

@Configuration
@EnableJms
public class JmsConfig {
}

JmsTemplate

Шаблон для отправки сообщений:

@Service
public class MessageProducer {
    private final JmsTemplate jmsTemplate;

    public void sendToQueue(String destination, String message) {
        jmsTemplate.convertAndSend(destination, message);
    }
}

@JmsListener

Аннотация для получения сообщений:

@Component
public class MessageConsumer {
    @JmsListener(destination = "demo-queue")
    public void receiveQueue(String message) {
        log.info("Received: {}", message);
    }
}

Pub/Sub (Topic)

Для работы с топиками нужен отдельный containerFactory:

@Bean
public JmsListenerContainerFactory topicFactory(ConnectionFactory cf) {
    DefaultJmsListenerContainerFactory factory = new DefaultJmsListenerContainerFactory();
    factory.setConnectionFactory(cf);
    factory.setPubSubDomain(true);
    return factory;
}

@JmsListener(destination = "demo-topic", containerFactory = "topicFactory")
public void receiveTopic(String message) {
    log.info("[TOPIC] Received: {}", message);
}

6. Embedded vs Standalone

Характеристика Embedded Standalone
Где работает Внутри JVM приложения Отдельный процесс / Docker
Зависимость activemq-broker Только клиент (activemq-client)
Использование Тесты, демо, CI/CD Production, staging
Преимущества Быстрый старт, нет внешних зависимостей Масштабируемость, HA, кластеризация

8. Endpoint'ы API

POST /api/messages/queue
Отправить сообщение в очередь demo-queue
POST /api/messages/topic
Отправить сообщение в топик demo-topic
GET /api/messages/status

GET /api/messages/info

9. Тестирование через curl

Отправка в очередь

curl -X POST http://localhost:8893/api/messages/queue \
  -H "Content-Type: application/json" \
  -d '{"content":"hello queue"}'

Ожидаемый ответ:

{
  "status": "sent",
  "destination": "demo-queue",
  "message": "hello queue"
}

Отправка в топик

curl -X POST http://localhost:8893/api/messages/topic \
  -H "Content-Type: application/json" \
  -d '{"content":"hello topic"}'

Проверка статуса

curl http://localhost:8893/api/messages/status

Информация о брокере

curl http://localhost:8893/api/messages/info

10. Глоссарий терминов

Термин Описание
Message Broker Промежуточный компонент для асинхронной передачи сообщений между сервисами
Queue Очередь сообщений (point-to-point). Одно сообщение получает ровно один consumer
Topic Топик сообщений (publish/subscribe). Одно сообщение получают все подписчики
Producer Компонент, который создаёт и отправляет сообщения в брокер
Consumer Компонент, который получает и обрабатывает сообщения из брокера
JMS Java Message Service — стандартный API для работы с брокерами в Java
JmsTemplate Spring-шаблон для отправки JMS-сообщений
@JmsListener Spring-аннотация для создания JMS-consumer'а
ActiveMQ Classic Зрелый брокер сообщений от Apache с поддержкой множества протоколов
Embedded Режим, при котором брокер работает внутри JVM приложения
